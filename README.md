# BlueFairy Consent

Free cookie-consent plugin (Jira WPMAP-143). See readme.txt and FEATURES.md.

- Unit tests: `composer test` (stubs, no WordPress).
- Static analysis: `composer phpstan`, `composer phpcs`.
- Every method covered: `php bin/method-coverage.php` (needs pcov).
- Browser E2E: `tests/e2e/` (Playwright), run on the AWS test rig.
